                                           City Racer – Unity Car Racing Game

A Unity car racing game focused on performance optimization, gameplay systems, and clean architecture.
This project demonstrates advanced Unity development concepts useful for real-world game production.

         Key Features

Advanced Object Pooling System for road objects, rocks, and fuel pickups

Performance optimized spawning system

Age Restriction System (18+) before gameplay starts

Player profile input and display system

Mini Map for better road navigation

Car movement and gameplay animations

Save and Load player data using JSON serialization

          Technical Highlights

Built with Unity and C#

Optimized runtime using Object Pooling

Data persistence system using JSON

Clean modular scripting approach

Designed with scalable gameplay architecture

           Systems Implemented

Road and obstacle spawning

Fuel collection system

Rock obstacle system

Player information UI

Data saving and loading

Mini map navigation system

        Skills Demonstrated

Unity Game Optimization

Object-Oriented Programming (C#)

Game System Design

Performance Optimization

Data Persistence

Gameplay Architecture
